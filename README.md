# CATopalian PY HTML App Builder
This Python script is placed in the root of our HTML project folder and then we double click it to create a SINGLE HTML file of our entire project, which includes all the scripts and the CSS style! This makes it easy to share the app since it's now in one html file!

---

# Instructions
We place the pyw file in the root of our HTML project folder and then double click it.

This will create a single file that consists of all of the js scripts and the CSS style.

This makes it easy for us to share our app with people since it is now in one single file!

# Important
* Our html project file has to be named index.html

* Our subfolder must be named src

* Our next subfolders must be named js and css

* Our CSS project file needs to be named style001.css and must be in the folder named css, which is in the src folder.

---

So the idea is: 

The pyw file is located in the root project folder.  

In this root project folder we see the index.html file and the src folder.  

In the src folder we see the js folder and the css folder.

In the css folder we have one script named style001.css

In the js folder we have other folders, such as whenLoaded, updateTime etc.

In those js subfolers we can name our js files anything that we normally name them.

Now, when we double click the pyw file that is located in the root project folder, it will create a single HTML file that consists of all of the HTML, CSS and JS files all put into one file for easy reading and easy sharing!

---

### How to Download this App
1. Click the green Code Button on this github page
2. Choose Download ZIP
3. Save the Zip File
4. Extract All
5. Double click the the .pyw file to combine the HTML project files into ONE HTML file.
